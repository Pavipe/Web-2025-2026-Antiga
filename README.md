- Descripció
    BoiraSound és una pàgina web dedicada al festival de música BoiraSound situat als Camps Elisis de Lleida.
    La web permet consultar informació del festival, els artistes participants, els patrocinadors, una galeria d'imatges, preguntes freqüents, informació de contacte i informació legal.

    S'ha utilitzat HTML, CSS, JavaScript, Bootstrap 5, Font Awesome, Firebase Hosting

- Execució en local
    Pots fer qualsevol de les dos coses:
    - Obrir el fitxer index.html amb qualsevol navegador web 
    - Executar amb un servidor local - http.server - a la terminal cosa que crea un servidor local per visualitzar la web des del navegador.
    Després solament cal accedir a: http://localhost:8000

- Estructura principal
    - index.html - Pàgina principal de la web.
    - galeria.html - Mostra la galeria d'imatges del festival.
    - FAQ.html - Mostra les preguntes freqüents.
    - contacte.html - Mostra la ubicació i el formulari de contacte.
    - registre.html - Mostra el formulari de registre.
    - politica_privacitat.html - Mostra la política de privacitat.
    - politica_cookies.html - Mostra la política de cookies.
    - termes_condicions.html - Mostra els termes i condicions.
    - css/style.css - Conté els estils de la web.
    - js/codi.js - Conté les validacions dels formularis i els efectes JavaScript.
    - imatges/ - Conté les imatges i logotips utilitzats a la web.
